crt-subs-bookmarklet

One-click subdomain discovery via crt.name. No terminal.

Install

  1. Show your bookmarks bar (Ctrl+Shift+B)
  2. Drag this to the bar: crt-subs
  3. Click it on any in-scope page during recon

Manual fallback

If drag doesn't work, copy dist/bookmarklet.txt into a new bookmark's URL field.

Source: crt.name free API, 100 req/IP/day. Passive CT lookup only — test authorized targets.
